# Cosmos Space Dashboard 🚀

## 🌌 About The Project
**Cosmos Space** is an interactive web application dedicated to space and astronomy. The project provides a visual and informative experience for users by displaying a daily updated space image, tracking upcoming space launch schedules, and presenting detailed data about planets in our solar system (such as gravity, number of moons, and other characteristics).

The primary goal of building this project was practical training on integrating external APIs with the front-end and directly manipulating the DOM to create dynamic content using JavaScript.

---

## ✨ Features
* **Astronomy Picture of the Day:** Displays a daily space image or video along with a simplified scientific description.
* **Space Launch Schedule:** Tracks and shows the dates and times of upcoming spacecraft launches and missions.
* **Planetary Encyclopedia:** An interface that displays accurate data about planets (gravity, moons, and other properties).
* **Responsive UI:** A flexible design that seamlessly adapts to all screen sizes.

---

## 💻 Tech Stack
* **HTML5**
* **CSS3**
* **Tailwind CSS** (For rapid & responsive styling)
* **Vanilla JavaScript** (DOM Manipulation & Fetch API)

---

## 🧠 Learning Outcomes
* Fetching data from multiple external APIs simultaneously.
* Handling Promises and Async/Await in JavaScript.
* Dynamically updating and modifying HTML elements (DOM) based on server responses.
* Building modern, responsive interfaces using the Tailwind CSS framework.

---

## 🚀 Getting Started
To run the project locally on your machine, follow these steps:

1. Clone the repository using Git.
2. Open the project folder in your preferred code editor (e.g., VS Code).
3. Run the **index.html** file in your browser (using the Live Server extension is recommended for the best experience).

---
The APIs used in this project are:

## 🔗 APIs Used
* **NASA APOD API:** Fetches the Astronomy Picture of the Day and its scientific details.
* **Space Launch Now API:** Fetches upcoming space launch schedules, mission details, and dates.
* **Solar System OpenData API:** Provides comprehensive data about solar system planets (gravity, moons, etc.).
